# TaskFlow

Application de gestion de tâches avec architecture répartie :
un client (PHP) qui consomme une API REST (Python).

## Architecture

- `api/` : API REST en Python (Flask), gère les tâches et la base de données
- `client/` : Interface web en PHP, consomme l'API
